General-purpose audio production and analysis workspace — Claude Code cloud environment `Audio Production`.

## MCP servers

`.mcp.json` registers [mathlas](https://github.com/Archerkattri/mathlas) (`uvx mathlas-mcp`, math search and numeric/Lean verification, no API key). Every session that opens this repo loads it. `.claude/settings.json` also lists it in `enabledMcpjsonServers` so interactive sessions should not prompt for approval; if one does, approve it once.

General-purpose audio production and analysis workspace — Claude Code cloud environment `Audio Production`.

## MCP servers

`.mcp.json` registers [mathlas](https://github.com/Archerkattri/mathlas) (`uvx mathlas-mcp`, math search and numeric/Lean verification, no API key). It is pre-approved via `enabledMcpjsonServers` in `.claude/settings.json`, so every session that opens this repo loads it without a prompt.
